# Corestone Partners Redesign

Analyze https://corestonepartners.de/ and recreate the entire website frontend, including every page, section, navigation item, and existing feature. Keep the same business purpose and content structure, but redesign everything with a 100x better, premium institutional-finance aesthetic: serious, elegant, modern, and trustworthy. Use sophisticated typography, refined spacing, a restrained dark navy/white palette, subtle gold accents, high-quality imagery, polished animations, and exceptional responsive design. Implement all pages and interactions, including menus, buttons, forms, and mobile navigation. Use React, TypeScript, and Tailwind CSS. Make it feel like a world-class private equity/investment firm website, not a generic AI template. Focus on outstanding UI/UX, consistency, accessibility, and production-quality frontend code. Frontend only; no backend. First inspect the reference website thoroughly, then build the complete experience.
